# Hot reloading DSP in Hamburger

Made this for myself to iterate faster on implementing distortion types and other effects. Compile times here are so much better.

# how to use

1: create a new folder within `./hotdsp` and call it whatever (e.g: "example")
2: create an initdsp.cpp file
3: create an instance class (e.g: "Example") which inherits from "HotDsp" and call `HOTDSP_EXPORT (Example)` on the class

build the target called "<folder_name>_dsplib" (e.g: "example_dsplib" or whatever it will be autogenerated as)
in hamburger select DLL as a distortion type, and select the generated library file created.

Hamburger will auto hot reload when it detects file changes on the selected DLL. Enjoy!
